# 复现性诊断：换一台机器后，结果还能复现吗？

> 2026-11-23。原实验在 8×RTX PRO 6000 上完成；交付前用仓库脚本在 **4×B200** 上从干净 checkout 重跑。
> 第一轮 4 卡并行复跑得到 15.7 / 17.7 / 22.9 / 35.5，看起来"复现不出来"。本文档记录排查过程与最终结论。
> 原始日志：`results/repro_b200/logs/*.log.gz`（gzip）；B200 上的逐题 benchmark 与配对检验：
> `results/bench_b200/`（含 `boot_*.json`）。

## 0. 结论速览

| # | 结论 | 证据 |
|---|---|---|
| 1 | **主要结论在 B200 上全部复现**：MAS 显著优于 SQ；分模态 vs 统一 scale 打平；混合校准在 C4 上显著改善；W4A8 未追平 FP16 | §3 |
| 2 | **不是"换 GPU 导致不可复现"**：同一台 B200、同一张卡、同一种子，连续两次训练就不同（19.19 / 17.57）。原机器上也一样（17.03 / 18.46 / 19.89） | §2.3 |
| 3 | **训练噪声来自反向的非确定性归约**：`MAS_DETERMINISTIC=1` 下两次 PPL **20.126422882080078 逐位相同** | §2.4 |
| 4 | **冻结 checkpoint 后的评测完全可复现**：同一 checkpoint 在 3 张卡上评 PPL 均为 **18.510595321655273** | §2.2 |
| 5 | **跨硬件只有很小的系统偏移**：FP16 PPL 差 5×10⁻⁵；FP16 逐题回答 97% / 96% 逐字相同。量化路径因 `act_scales`（取 max 的统计）对前向数值差敏感，偏移 0.5~5% | §2.1 |
| 6 | **那个 35.5 是一次"训练早期发散"**：第 1 层的 loss 从第一步起就是正常值的 1.9 倍，并一路传到最后一层。18 次里出现 1 次 | §2.5 |
| 7 | **B200 上 MAS+混合校准（14 次非并行）wikitext2 为 17.42 ± 1.24**，原机器 16.35 ± 0.54（6 次），均值差约 1 个点、处于训练噪声量级 | §2.6 |

**一句话**：不是 GPU 型号让结果"复现不出来"，而是**训练本身就带噪声**（原机器也有），加上第一轮复跑恰好碰到一次早期发散。
固定 checkpoint 的结果在任何卡上都逐位一致；主结论的方向和显著性在 B200 上都成立。

## 2. 排查：把流程切成三段，分别测能否复现

链路是：加载模型 → 统计 `act_scales` → 闭式解初始化 → **训练** → 评测。

### 2.1 不训练的路径（原机器上逐位确定）——只有小的系统偏移

| 配置 | 原机器 | B200 | 相对差 |
|---|---|---|---|
| FP16 (W16A16) | 11.108325 | 11.108918 | **+5×10⁻⁵** |
| RTN W4A8 | 6076.08 | 6103.45 | +0.45% |
| SmoothQuant（闭式解） | 22.631 | 21.512 | −4.9% |
| MAS 仅初始化（闭式解） | 19.428 | 19.273 | −0.8% |
| NVFP4 W4A4 + MAS 闭式解 | 11.748 | 11.725 | −0.2% |

FP16 逐题对比（同一份 benchmark 子集）：

| | ScienceQA（2017） | TextVQA（2000） |
|---|---|---|
| 准确率（原 / B200） | 80.61 / 80.81 | 75.78 / 75.85 |
| 逐题对错一致率 | 99.3% | 98.2% |
| 回答文本逐字相同 | 97.3% | 95.7% |

**FP16 几乎无差异 → 模型、数据、评测代码都没问题。** 量化路径的偏移来自 `act_scales`：
同一份校准数据，两台机器统计出的 1008 个张量里只有 255 个逐位相同，相对差中位数 1.8%、最大 66%
（例如 `layers.34.mlp.down_proj.vision_scale` 110.5 → 73.4）。激活**最大值**统计对前向的微小数值差极其敏感，
闭式解尺度 $s=\sqrt{\max|x|/\max|w|}$ 直接由它决定，再经量化（分段函数）放大，于是 PPL 偏移 0.5~5%。

### 2.2 评测（冻结 checkpoint）——逐位可复现

同一份 `mas_parameters.pth` 在 B200 的 GPU0/1/2 上各评一次：三次都是 `18.510595321655273`。
**所以报告里的 benchmark / PPL，只要给定 checkpoint，任何人都能逐位复算**（`results/` 里存的逐题结果即可复核）。

### 2.3 训练——同卡同种子也不一样（这才是噪声的来源）

MAS + 混合校准 0.5，同一种子 seed=2，B200 上所有运行：

| 运行方式 | wikitext2 PPL |
|---|---|
| GPU0 连续两次 | 19.19 / 17.57 |
| GPU1 连续两次 | 17.88 / 18.13 |
| GPU3 连续两次 | 16.70 / 17.79 |
| 单独一次 | 18.51 |
| 其他 GPU 在跑评测时，GPU0 上连续三次 | 15.91 / 16.01 / 16.45 |
| GPU2 上连续四次 | 19.66 / 17.99 / 15.90 / 16.21 |
| 4 卡同时训练一轮 | 15.70 / 17.73 / 22.93 / **35.52** |

**同一张卡连跑两次就差 1.6，连跑四次跨度 3.8**。原机器上的记录也是如此（实验报告 §1.2：17.03 / 18.46 / 19.89）。
所以"换卡后数字不同"首先是因为**这个训练过程本身就不可逐位复现**，与卡的型号无关。

### 2.4 机制：反向传播的非确定性归约

开启 `MAS_DETERMINISTIC=1`（固定 cuBLAS workspace、禁用 flash / mem-efficient SDPA）连跑两次：

```
detm_a: wikitext2 : 20.126422882080078
detm_b: wikitext2 : 20.126422882080078    ← 逐位相同
```

关掉后立即恢复随机波动。**结论与原机器上的定位一致**：噪声来自训练时 attention 反向的原子累加
（归约顺序不固定）。注意确定性模式强制 math SDPA，绝对值偏高（原机器 24.11、B200 20.13），只用于排查，不用于报数。

### 2.5 那个 35.5 是怎么回事：训练早期发散

逐层对比训练 loss（第 2 个 epoch，节选）：

| 层 | 发散那次（35.5） | 正常一次（15.9） |
|---|---|---|
| 0 | 0.0576 | 0.0576 |
| **1** | **0.1201** | 0.0645 |
| 2 | 0.1504 | 0.0767 |
| 10 | 0.3379 | 0.2275 |
| 20 | 0.3867 | 0.3008 |
| 35 | 2.0938 | 1.9922 |

第 0 层完全一样；**第 1 层第一个 epoch 的平均 loss 就已是正常值的 1.9 倍**，之后每层都偏高。
MAS 是逐层优化（下一层的输入是上一层量化后的输出），一层出事会一路传下去。
18 次运行里只有这 1 次是这种形态。另一个偏高的 22.9 逐层 loss 正常，属于普通的噪声尾部。

> 能说的：发散发生在优化的最开始（`let_lr=5e-2`、AdamW、无梯度裁剪、bf16），由非确定性梯度触发。
> 不能说的："并行训练导致发散"。1 次发散、样本太少，无法归因；另一组"其他卡忙时"的 3 次反而是最好的一组。

### 2.6 B200 上的分布

| 配置（B200） | n | mean ± std | 中位数 | 原机器 |
|---|---|---|---|---|
| MAS + 混合 0.5（不含 4 卡并行那轮） | 14 | 17.42 ± 1.24 | 17.68 | 16.35 ± 0.54（6） |
| MAS + 混合 0.5（含 4 卡并行那轮） | 18 | 18.65 ± 4.56 | 17.76 | — |
| MAS + 原校准 | 9 | 19.09 ± 1.45 | 18.75 | 18.46 ± 1.43（3） |
| 统一 scale + 混合 0.5 | 12 | 18.56 ± 2.06 | 17.88 | 17.20 ± 0.82（3） |

wikitext2 PPL 的离散度很大且有长尾（统一 scale 也有 23.96 这样的单次值），
**PPL 的均值和 std 都不稳定，中位数更稳健**。下面看更稳的 C4 和 benchmark。

## 3. 主要结论在 B200 上是否成立

### 3.1 C4 PPL（冻结 checkpoint 逐个评测）

| 配置（B200） | n | C4 PPL | 原机器 |
|---|---|---|---|
| MAS + 原校准 | 9 | 20.40 ± 0.46 | 20.21 ± 0.23（4） |
| **MAS + 混合 0.5** | 14 | **18.88 ± 0.50** | 18.53 ± 0.11（3） |
| 统一 scale + 混合 0.5 | 12 | 19.16 ± 0.69 | 18.61 ± 0.17（3） |

- **混合校准的收益复现**：−1.52（原机器 −1.69），Mann–Whitney **p = 0.0001**（wikitext2 上 p = 0.008）；
- **分模态 vs 统一 scale 仍打平**：C4 p = 0.20，wikitext2 p = 0.16；
- C4 上的离散度只有 wikitext2 的一半左右，且没有长尾——C4 是更可靠的比较指标。

### 3.2 多模态 benchmark（同题配对 bootstrap，SQA n=2000、TextVQA n=2000）

| 对比（B200） | ScienceQA | TextVQA | 原机器 |
|---|---|---|---|
| MAS − SmoothQuant | **+3.40 [+1.70, +5.05]** | **+2.42 [+0.84, +4.00]** | +3.17 / +3.41，均显著 |
| MAS − 统一 scale | −0.05 [−1.35, +1.25] | −0.91 [−2.40, +0.63] | −0.30 / +0.54，均不显著 |
| MAS − FP16 | **−2.15 [−3.45, −0.85]** | **−12.38 [−14.02, −10.79]** | −1.93 / −9.79，均显著 |

**三条主结论的方向和显著性完全一致。** 同一配置的绝对准确率在两台机器上相差 0.6~2.5 点
（例如 MAS 混合 0.5：SQA 79.38 → 78.78，TVQA 65.98 → 63.47），这与"每次训练得到的 checkpoint 不同"一致：
两台机器上 MAS 的逐题对错一致率为 92%（SQA）/ 84%（TVQA），而 FP16 是 99% / 98%。

## 4. 对报告与答辩的口径

1. **结论可复现，数字不可逐位复现。** 方向、排序、显著性跨硬件成立；具体的 PPL 均值与 std 依赖环境和运气。
2. 报告里的 `16.35 ± 0.54` 是原环境 6 次的统计。B200 上 14 次是 17.42 ± 1.24。引用时带上环境与次数。
3. **PPL 优先看 C4 或中位数**：wikitext2 有长尾（单次 35.5），会把均值和 std 拉坏。
4. 想逐位复现，只能复用 checkpoint（`results/` 已提供逐题结果）或开 `MAS_DETERMINISTIC=1`（精度偏低，只做排查）。
5. 被问"为什么复现不出来"时：**同一张卡跑两次就不同**，这是 MAS 逐层训练 + 非确定性反向的固有性质，
   所以本工作坚持多次重复 + 配对检验——这也是对论文"只报单次结果"的一个具体批评。

## 5. 复现本文档的实验

```bash
export MODEL=/path/to/Qwen2.5-VL-3B-Instruct MASQUANT_DATA_ROOT=/path/to/data   # 见使用说明的数据准备

# (a) 不训练的确定性路径
W=16 A=16 TASKS= bash scripts/train_eval.sh base_fp16    0 rtn      text-vision
TASKS=        bash scripts/train_eval.sh base_sq      0 sq       text-vision
TASKS=        bash scripts/train_eval.sh base_masinit 0 mas_init text-vision

# (b) 同一 checkpoint 重复评测（应逐位相同）
for g in 0 1 2; do TASKS= bash scripts/bench_ckpt.sh evalrep$g $g split_scales outputs/xxx/mas_parameters.pth --eval_ppl; done

# (c) 训练非确定性：同卡两次 vs 确定性模式两次
TASKS= bash scripts/train_eval.sh det_a 0 mas text-vision-mix
TASKS= bash scripts/train_eval.sh det_b 0 mas text-vision-mix
MAS_DETERMINISTIC=1 TASKS= bash scripts/train_eval.sh detm_a 0 mas text-vision-mix
MAS_DETERMINISTIC=1 TASKS= bash scripts/train_eval.sh detm_b 0 mas text-vision-mix

# (d) C4 上评测冻结 checkpoint
MAS_PPL_DATASETS=c4 TASKS= bash scripts/bench_ckpt.sh c4_x 0 split_scales outputs/xxx/mas_parameters.pth --eval_ppl
```
`scripts/env.sh` 里统一了 `MODEL` / `MASQUANT_DATA_ROOT` 等路径，可先 export 覆盖；
`experiments/` 下是原始实验脚本（含批量并行版），与上述一键脚本等价。
