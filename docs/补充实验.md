# 补充实验（2026-11-23，4×B200 上重跑）

> 复现性排查见 [`复现性诊断.md`](复现性诊断.md)。本文档记录**在原实验机之外新增的三组实验**：
> ① W4A4 NVFP4 的下游 benchmark（此前只有 PPL）；② W4A6 的下游 benchmark（此前只有 PPL）；
> ③ 训练学习率对 PPL 的稳健性。
>
> 环境：4×B200，其余同主报告。benchmark 为 SQA 前 2000 题 + TextVQA 前 2000 题，
> **同一批题目做配对 bootstrap（10000 次）**；因为题目集相同，可以和主报告的子集结果对照方向。
> 原始逐题结果：`results/bench_b200/`、`results/cmc_b200/`；bootstrap 输出：同目录 `boot_*.json`。
>
> 本轮新增第 ④ 组：**CMC（论文的低秩跨模态补偿）在 4000 题上的下游评测与单层诊断**，见 §4。

## 1. W4A4 NVFP4 的下游结果：几乎无损（本文最有价值的新结果）

主报告里 NVFP4 只测了 PPL（11.75 vs FP16 11.11）。补上下游 benchmark 后结论强得多：

| 配置 | 位宽 | ScienceQA | TextVQA |
|---|---|---|---|
| FP16 | 16/16 | **80.80** | **75.85** |
| NVFP4 RTN | **4/4** | 80.25 | 73.72 |
| **NVFP4 + MAS 闭式解** | **4/4** | **80.45** | **73.64** |
| MAS（INT，混合校准） | 4/8 | 78.65 | 63.47 |
| SmoothQuant（INT） | 4/8 | 75.25 | 61.05 |

配对差异（相对 FP16）：

| 对比 | ScienceQA | TextVQA |
|---|---|---|
| FP16 − NVFP4 RTN | +0.55 [−0.40, +1.55] **不显著** | **+2.14 [+1.20, +3.08] 显著** |
| FP16 − NVFP4 + MAS | +0.35 [−0.65, +1.40] **不显著** | **+2.21 [+1.23, +3.22] 显著** |
| FP16 − MAS（INT W4A8） | **+2.15 [+0.85, +3.50] 显著** | **+12.38 [+10.72, +14.03] 显著** |

**要点**：

1. **W4A4 的 NVFP4 在 ScienceQA 上与 FP16 统计上无差异**（+0.35），TextVQA 只差 2.2 点；
   而 INT W4A8 的 MAS 在 TextVQA 上差 12.4 点。**FP4 用一半的位宽，视觉密集任务上比 INT 4-bit 权重 8-bit 激活高约 10 个百分点。**
   这直接说明：多模态量化的瓶颈不只是"多少个 bit"，而是**格式是否适应视觉 token 的离群分布**（块级缩放 vs per-token）。
2. **MAS 的闭式解在这个设置下就够**：NVFP4 + MAS（80.45 / 73.64）与 NVFP4 裸 RTN（80.25 / 73.72）在所有指标上都不显著，
   与 PPL 侧的结论（训练反而略差）一致。**FP4 下推荐直接用闭式解初始化。**
3. 注意 NVFP4 的这两个结果都是**单次**（RTN 与闭式解本身是确定性的，**不是**训练产物，所以重复无意义）。

## 2. W4A6 的下游结果：PPL 的下降没有反映到下游

主报告里 W4A6 只有 PPL（SQ 27.48 / MAS 25.71），看起来"比 W4A8 差一点"。补上下游后：

| 配置（W4A6） | PPL | ScienceQA | TextVQA |
|---|---|---|---|
| SmoothQuant | 26.72 | 71.60 | 53.32 |
| MAS + 混合校准 | 24.48 | **75.85** | 53.12 |

| 配对差异 | ScienceQA | TextVQA |
|---|---|---|
| MAS − SQ | **+4.25 [+2.30, +6.20] 显著** | −0.19 [−2.17, +1.75] **不显著** |

对照 W4A8：MAS 78.65 / 63.47，SQ 75.25 / 61.05。

**三点**：

1. **6-bit 激活在 TextVQA 上崩了**：MAS 从 W4A8 的 63.47 掉到 53.12（−10.3，显著），
   而 PPL 只从 16.35 涨到 24.48。**PPL 与下游背离在这里极其明显**——如果只看 PPL，会以为 W4A6"只是稍差"。
2. **MAS > SQ 的能力依赖任务**：W4A6 下 ScienceQA 上 MAS 显著优于 SQ（+4.25），
   但 TextVQA 上两者都崩到 53 附近、没有差异。说明当激活位宽低到某个程度，TextVQA 这类任务的瓶颈已经不再是"平滑是否分模态"。
3. 这也是对论文 W4A6 行的一个补充：论文 Table 1 的 W4A6 平均分（59.7 vs FP16 70.1）掩盖了任务间的巨大差异。

## 3. 训练学习率：调小无法降低方差，且更差

复现性排查里发现单次训练 PPL 波动大（`let_lr=5e-2`、AdamW、无梯度裁剪）。试着把 `--let_lr` 调到 1e-2：

| `let_lr` | wikitext2 | C4 | n |
|---|---|---|---|
| **5e-2（默认）** | 17.42 ± 1.24 | **18.88 ± 0.50** | 14 / 14 |
| 1e-2 | 18.99 ± 0.47 | 20.43 ± 0.12 | 4 / 4 |

**结论：调小学习率方差确实小了（C4 ±0.12 vs ±0.50），但均值差 1.5 个点、方向一致地变差**——
这不是"更稳"，而是"稳定地更差"（2 个 epoch 内没收敛够）。**保持默认 5e-2**。

> 这条的价值在于记录：量化 PTQ 的可复现性问题不能靠降学习率解决；要么多次重复，要么固定确定性后端做排查。

## 4. CMC 低秩补偿：在混合校准的 checkpoint 上显著有害

论文的 CMC 只存一份 $Q(S_tW)$，视觉 token 用自己的尺度 $S_v$，再加低秩旁路 $X S_v^{-1} L R$ 补偿
$S_vW - Q(S_tW)$。此前我们只有 n=500 的结果（CMC 相对"不补偿"−1.6 / −0.6，不显著）。
本轮用 MAS+混合校准的 checkpoint 在 SQA 2000 + TextVQA 2000 上完整评测，并做了单层诊断。

### 4.1 下游结果（同一 checkpoint，配对 bootstrap）

| 配置 | 低秩参数 | ScienceQA | TextVQA |
|---|---|---|---|
| **不补偿**（所有 token 用文本尺度，一份权重） | 0 | **79.55** | 63.35 |
| 理想上界（视觉单独一份 $Q(S_vW)$，即训练路径） | — | 78.65 | 63.47 |
| CMC，rank 0.05（论文默认） | ~1 GB | 78.45 | **56.48** |
| CMC，rank 0.2 | ~4 GB | 79.30 | 62.24 |
| CMC，自适应 rank（同预算，平均秩 72.5） | ~0.96 GB | 75.40 | 51.04 |

| 配对差异（不补偿 − X） | ScienceQA | TextVQA |
|---|---|---|
| − CMC r0.05 | +1.10 [−0.30, +2.50] | **+6.86 [+5.19, +8.54] 显著** |
| − CMC r0.2 | +0.25 [−0.90, +1.35] | +1.10 [−0.24, +2.45] |
| − CMC 自适应 | **+4.15 [+2.60, +5.65] 显著** | **+12.30 [+10.39, +14.27] 显著** |
| − 理想上界 | +0.90 [−0.15, +1.95] | −0.13 [−1.45, +1.21] |

同一 checkpoint 的 CMC 评测独立跑了两次，逐题结果**逐字节相同**（评测完全确定，差异不是噪声）。

**结论**：
1. **论文默认 rank 0.05 的 CMC 让 TextVQA 掉 6.9 个点**；加大到 rank 0.2（参数 4 倍）才回到"不补偿"的水平，但仍不超过它。
2. **"不补偿"与理想上界打平** —— 在混合校准的 checkpoint 上，**文本尺度对视觉 token 已经够用**，
   CMC 想逼近的那个上界本身就没有收益空间。
3. **主报告里"自适应 rank 省 7.8% 参数、PPL 不变"这一改进必须撤回**：PPL 不变是因为纯文本 PPL 根本不经过视觉旁路
   （主报告 §4.2 自己就指出了这一点），下游一测，它比固定 rank 还差（TextVQA 51.0）。

### 4.2 为什么之前 n=500 时看不出来：取决于 checkpoint

同样在 B200 上，把**旧 checkpoint（原校准）**也重新跑一遍 CMC（白化与低秩分解在 B200 上重算，同样 500 题）：

| checkpoint | 机器 | 不补偿 | CMC r0.05 | 差（TextVQA） |
|---|---|---|---|---|
| 原校准（旧） | 原机器 | 63.34 | 62.74 | +0.60 |
| 原校准（旧） | **B200** | 61.04 | 60.30 | +0.74（不显著） |
| 混合校准（新） | B200 | 62.54 | 54.26 | **+8.28** |

**旧 checkpoint 在两台机器上结论一致（CMC 小幅有害、不显著）；换成混合校准的 checkpoint 后 CMC 大幅有害。**
所以这不是硬件问题，而是 CMC 的效果依赖于 checkpoint。

### 4.3 机制：单层 SQNR 的均值掩盖了少数被"补偿坏"的层

`tools/cmc_probe.py`：在真实视觉 token 上，逐层比较三种算法相对 FP16 输出的 SQNR
（每 3 层取一层，共 72 个模块；前 32 张图是白化用过的校准集，后 16 张是未见过的）：

| checkpoint | 数据 | 不补偿 | 理想上界 | CMC r0.05 | CMC 比不补偿差的模块数 |
|---|---|---|---|---|---|
| 原校准（旧） | 未见 | 15.16 dB | 17.29 dB | 17.17 dB | 10 / 72 |
| 混合校准（新） | 未见 | **16.82 dB** | 17.17 dB | 18.05 dB | **23 / 72** |

最差的几个模块（混合校准，未见数据）：

| 模块 | 不补偿 | 理想 | CMC |
|---|---|---|---|
| `layers.3.self_attn.k_proj` | 12.12 | 11.15 | **3.52** |
| `layers.9.self_attn.v_proj` | 16.24 | 15.74 | 13.98 |
| `layers.33.self_attn.k_proj` | 14.12 | 14.21 | 11.92 |

三点观察：

1. **CMC 的平均 SQNR 反而最高**（18.05 dB，甚至高于理想上界）——因为 `quant_cmc=0` 时低秩项也顺带补了
   $Q(S_tW)$ 的 4-bit 量化误差。**只看平均 SQNR 会得出"CMC 有效"的结论，而下游掉了 7 个点。**
   这与 RTN 那条教训完全一样：均值掩盖了少数模块的崩坏（`layers.3.k_proj` 从 12 dB 掉到 3.5 dB，
   K 投影出错会直接破坏注意力）。
2. **混合校准让文本尺度本身就适合视觉 token**：新 checkpoint 上"不补偿"已接近理想上界（16.82 vs 17.17），
   CMC 能补的空间很小，而截断到 5% 秩留下的残差 $(S_v - S_t)W$ 的高秩部分在 23 个模块上反而大于收益。
   旧 checkpoint 上"不补偿"差理想 2.1 dB，CMC 有东西可补，坏模块也少（10 个）。
3. **不是数值问题**：低秩因子没有触发 ±65500 的 clamp，最大 |L| 仅 0.13；在 fp32 下重算，坏模块依旧。
   也不是过拟合白化校准集：校准集上同样有 18 个模块变差。说明**论文的假设**——"白化后模态间的权重差是低秩的"——在这些模块上不足以覆盖残差：截断后剩下的高秩部分比"不补偿"的量化误差还大。

### 4.4 对论文与对我们方案的意义

- 论文 Fig.6 用**平均 SQNR**论证"rank 0.08 就够"，本实验说明平均 SQNR 不足以支持这个结论，
  应该报逐模块最差值或直接报下游。
- **实用建议**：用混合校准训练 MAS 后，**部署时直接只用文本尺度、不加低秩旁路**——
  一份 4-bit 权重、零额外参数、无额外 prefill 开销，下游与理想上界打平，且显著优于论文默认的 CMC。
  这也再次印证主报告的主线：**收益来自校准数据的模态平衡，而不是"分模态 + 补偿"这套结构。**

## 5. 与主报告的关系

- 主报告 §4.3（benchmark 主表）与 §4.4（NVFP4）的结论**方向全部成立**，绝对值见各自表格的环境说明；
- **NVFP4 一节应升级**：从"PPL 接近无损"改为"下游接近无损、且显著优于 INT W4A8"；
- W4A6 一节应补下游：**激活降到 6 bit 时 TextVQA 崩溃，PPL 看不出来**；
- **CMC 一节应改写**：论文默认的 CMC 在混合校准的 checkpoint 上显著有害，自适应 rank 的"改进"撤回（§4）。

## 6. 复现命令

```bash
export MODEL=/path/to/Qwen2.5-VL-3B-Instruct MASQUANT_DATA_ROOT=/path/to/data

# W4A4 NVFP4（闭式解，确定性）
W=4 A=4 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh nvfp4_mas  0 mas_init text-vision --wfmt nvfp4 --afmt nvfp4
W=4 A=4 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh nvfp4_rtn  0 rtn      text-vision --wfmt nvfp4 --afmt nvfp4

# W4A6
W=4 A=6 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh w4a6_sq     0 sq  text-vision
W=4 A=6 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh w4a6_mas_mix 0 mas text-vision-mix

# CMC：不补偿 / CMC / 单层诊断
MAS_NO_CMC=1 python infer_mas.py --mode infer --model $MODEL --net qwen2.5-vl-3b --scales_path <mas_parameters.pth> \
    --wbits 4 --abits 8 --quantize --n_cali_samples 32 --cali_data_type vision-audio-only --quant_cmc 0 --rank 0.05 \
    --tasks_multimodal scienceqa_img,textvqa_val --limit_multimodal 0.4 --output_dir outputs_cmc/nocomp
python infer_mas.py ...（同上，去掉 MAS_NO_CMC，加 --LR；rank 0.2 改 --rank 0.2；自适应加 --adaptive_rank greedy --rank_min 32 --rank_cap 0.05）
python tools/cmc_probe.py --model $MODEL --scales <mas_parameters.pth> \
    --adapters low_rank_adapters/<...>_rank0.05.pt --nsamples 48 --calib-n 32 --layer-step 3

# 学习率
TASKS= PPL_SETS=wikitext2,c4 bash scripts/train_eval.sh lr01 0 mas text-vision-mix --let_lr 1e-2

# 配对检验
python tools/paired_bootstrap.py --runs fp16=outputs_bench/fp16 nvfp4_mas=outputs_bench/nvfp4_mas \
    mas_w4a8=outputs_bench/mas_w4a8 --tasks scienceqa_img textvqa_val --ref fp16
```
