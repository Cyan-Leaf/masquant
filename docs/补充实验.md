# 补充实验（2026-11-23，4×B200 上重跑）

> 复现性排查见 [`复现性诊断.md`](复现性诊断.md)。本文档记录**在原实验机之外新增的三组实验**：
> ① W4A4 NVFP4 的下游 benchmark（此前只有 PPL）；② W4A6 的下游 benchmark（此前只有 PPL）；
> ③ 训练学习率对 PPL 的稳健性。
>
> 环境：4×B200，其余同主报告。benchmark 为 SQA 前 2000 题 + TextVQA 前 2000 题，
> **同一批题目做配对 bootstrap（10000 次）**；因为题目集相同，可以和主报告的子集结果对照方向。
> 原始逐题结果：`results/bench_b200/`；bootstrap 输出：同目录 `boot_*.json`。

## 1. W4A4 NVFP4 的下游结果：几乎无损（本文最有价值的新结果）

主报告里 NVFP4 只测了 PPL（11.75 vs FP16 11.11）。补上下游 benchmark 后结论强得多：

| 配置 | 位宽 | ScienceQA | TextVQA |
|---|---|---|---|
| FP16 | 16/16 | **80.80** | **75.85** |
| NVFP4 RTN | **4/4** | 80.25 | 73.72 |
| **NVFP4 + MAS 闭式解** | **4/4** | **80.45** | **73.64** |
| MAS（INT，混合校准） | 4/8 | 78.65 | 63.47 |
| SmoothQuant（INT） | 4/8 | 75.25 | 61.05 |

配对差异（相对 FP16）：

| 对比 | ScienceQA | TextVQA |
|---|---|---|
| FP16 − NVFP4 RTN | +0.55 [−0.40, +1.55] **不显著** | **+2.14 [+1.20, +3.08] 显著** |
| FP16 − NVFP4 + MAS | +0.35 [−0.65, +1.40] **不显著** | **+2.21 [+1.23, +3.22] 显著** |
| FP16 − MAS（INT W4A8） | **+2.15 [+0.85, +3.50] 显著** | **+12.38 [+10.72, +14.03] 显著** |

**要点**：

1. **W4A4 的 NVFP4 在 ScienceQA 上与 FP16 统计上无差异**（+0.35），TextVQA 只差 2.2 点；
   而 INT W4A8 的 MAS 在 TextVQA 上差 12.4 点。**FP4 用一半的位宽，视觉密集任务上比 INT 4-bit 权重 8-bit 激活高约 10 个百分点。**
   这直接说明：多模态量化的瓶颈不只是"多少个 bit"，而是**格式是否适应视觉 token 的离群分布**（块级缩放 vs per-token）。
2. **MAS 的闭式解在这个设置下就够**：NVFP4 + MAS（80.45 / 73.64）与 NVFP4 裸 RTN（80.25 / 73.72）在所有指标上都不显著，
   与 PPL 侧的结论（训练反而略差）一致。**FP4 下推荐直接用闭式解初始化。**
3. 注意 NVFP4 的这两个结果都是**单次**（RTN 与闭式解本身是确定性的，**不是**训练产物，所以重复无意义）。

## 2. W4A6 的下游结果：PPL 的下降没有反映到下游

主报告里 W4A6 只有 PPL（SQ 27.48 / MAS 25.71），看起来"比 W4A8 差一点"。补上下游后：

| 配置（W4A6） | PPL | ScienceQA | TextVQA |
|---|---|---|---|
| SmoothQuant | 26.72 | 71.60 | 53.32 |
| MAS + 混合校准 | 24.48 | **75.85** | 53.12 |

| 配对差异 | ScienceQA | TextVQA |
|---|---|---|
| MAS − SQ | **+4.25 [+2.30, +6.20] 显著** | −0.19 [−2.17, +1.75] **不显著** |

对照 W4A8：MAS 78.65 / 63.47，SQ 75.25 / 61.05。

**三点**：

1. **6-bit 激活在 TextVQA 上崩了**：MAS 从 W4A8 的 63.47 掉到 53.12（−10.3，显著），
   而 PPL 只从 16.35 涨到 24.48。**PPL 与下游背离在这里极其明显**——如果只看 PPL，会以为 W4A6"只是稍差"。
2. **MAS > SQ 的能力依赖任务**：W4A6 下 ScienceQA 上 MAS 显著优于 SQ（+4.25），
   但 TextVQA 上两者都崩到 53 附近、没有差异。说明当激活位宽低到某个程度，TextVQA 这类任务的瓶颈已经不再是"平滑是否分模态"。
3. 这也是对论文 W4A6 行的一个补充：论文 Table 1 的 W4A6 平均分（59.7 vs FP16 70.1）掩盖了任务间的巨大差异。

## 3. 训练学习率：调小无法降低方差，且更差

复现性排查里发现单次训练 PPL 波动大（`let_lr=5e-2`、AdamW、无梯度裁剪）。试着把 `--let_lr` 调到 1e-2：

| `let_lr` | wikitext2 | C4 | n |
|---|---|---|---|
| **5e-2（默认）** | 17.41 ± 1.10 | **19.02 ± 0.55** | 10 / 7 |
| 1e-2 | 18.99 ± 0.47 | 20.43 ± 0.12 | 4 / 4 |

**结论：调小学习率方差确实小了（C4 ±0.12 vs ±0.55），但均值差 1.4 个点、方向一致地变差**——
这不是"更稳"，而是"稳定地更差"（2 个 epoch 内没收敛够）。**保持默认 5e-2**。

> 这条的价值在于记录：量化 PTQ 的可复现性问题不能靠降学习率解决；要么多次重复，要么固定确定性后端做排查。

## 4. 与主报告的关系

- 主报告 §4.3（benchmark 主表）与 §4.4（NVFP4）的结论**方向全部成立**，绝对值见各自表格的环境说明；
- **NVFP4 一节应升级**：从"PPL 接近无损"改为"下游接近无损、且显著优于 INT W4A8"；
- W4A6 一节应补下游：**激活降到 6 bit 时 TextVQA 崩溃，PPL 看不出来**。

## 5. 复现命令

```bash
export MODEL=/path/to/Qwen2.5-VL-3B-Instruct MASQUANT_DATA_ROOT=/path/to/data

# W4A4 NVFP4（闭式解，确定性）
W=4 A=4 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh nvfp4_mas  0 mas_init text-vision --wfmt nvfp4 --afmt nvfp4
W=4 A=4 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh nvfp4_rtn  0 rtn      text-vision --wfmt nvfp4 --afmt nvfp4

# W4A6
W=4 A=6 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh w4a6_sq     0 sq  text-vision
W=4 A=6 TASKS=scienceqa_img,textvqa_val bash scripts/train_eval.sh w4a6_mas_mix 0 mas text-vision-mix

# 学习率
TASKS= PPL_SETS=wikitext2,c4 bash scripts/train_eval.sh lr01 0 mas text-vision-mix --let_lr 1e-2

# 配对检验
python tools/paired_bootstrap.py --runs fp16=outputs_bench/fp16 nvfp4_mas=outputs_bench/nvfp4_mas \
    mas_w4a8=outputs_bench/mas_w4a8 --tasks scienceqa_img textvqa_val --ref fp16
```
