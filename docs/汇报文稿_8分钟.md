## 0. 上台前必须知道的四件事

### 0.1 一句话主线（全场只讲这一条线）

> **论文的动机是对的，但归因错了：**
> 「分模态平滑」和「低秩补偿」这两个设计本身不带来增益；
> 真正有效的是 **校准数据的模态平衡**（零成本）和 **换掉权重求解器**（下游 +7.5）；
> 而这两件事是串联的——不先修校准集，更强的求解器反而有害。

这条线有三个优点：有转折（不是流水账）、有因果（A → F）、有自我否定（敢撤回自己的结论），
正好对应评分表里的「逻辑性」和「完成情况」。

### P2 · 背景（50s）

**页面**：左边一张对比图（视觉 token 与文本 token 的激活绝对值分布，**对数轴**，两条曲线错开 1~2 个数量级）；
右边三行字：`PTQ`、`SmoothQuant = 逐通道缩放，把离群值从激活搬到权重`、`多模态：一套缩放只能迁就一边`。

> 如果没有现成的图，就用 `fig4_sqnr.png` 或直接把「10–100×」这个数字放到最大字号。**不要为了这张图花时间重画。**

**口播**：

> 先把量化用一句话说清：把 fp16 的权重和激活换成 4 bit，模型小四倍，代价是掉点。
> 难点是激活里的离群通道——某一维比其它维大几百倍，一行只有一步长，被它撑爆，其余全压成 0。
> SmoothQuant 是这条线的标准做法：做一个逐通道缩放，把离群值从激活「搬」到权重上，数学上是恒等变换，量化之后才有区别。
> 多模态的问题在于：**视觉 token 的激活量级比文本大一到两个数量级**。一套缩放只能迁就一边——跟着视觉走，文本被过度压缩；跟着文本走，视觉撑爆步长。
> 论文管这个叫「平滑错位」。在 Qwen2.5-Omni 上，SmoothQuant 把语音识别的 WER 从 3.9 打到 77.4，基本没法用。

**任务**：50 秒内让所有人（包括没接触过量化的）明白「为什么多模态量化和纯文本量化不是一个问题」。
**这里不解释**：per-token / per-channel 的区别、量化误差公式、为什么 4bit 权重。一律留到问答。

### P3 · 论文两招（45s）

**页面**：左边 MAS（每个模态一套 $s_m$，闭式解初始化 → 逐层训练最小化重建误差）；
右边 CMC（只存文本的 $Q(S_tW)$，其它模态加低秩旁路，定理 2：白化后截断 SVD 是最优解）。
右下角一个小红框：`我们发现的笔误：Eq.(17) 分子分母写反`。

**口播**：

> 论文两个招。**MAS**：每个模态一套平滑因子，用本模态自己的统计做初始化，然后逐层训练，最小化重建误差。
> **CMC** 解决一个副作用：分模态的代价是每个模态都要存一份 4bit 权重，显存乘三，量化的意义就没了。所以只存文本那一份，其它模态加一条低秩旁路补差。它的定理挺漂亮——先白化，再截断 SVD 就是输出误差意义下的最优解。
> 顺带说一句我们精读时的发现：**定理 1 的公式分子分母写反了**。检验很简单——所有通道的模态范围比相等时，损失应该为 0，按原式算出来不是 0。

**任务**：45 秒讲完两个方法 + 一个加分点。笔误只用一句话，**不要展开推导**（评委追问再讲，见 Q3）。

### P5 · 核心发现：归因错了（50s）★

**页面**：`fig2_main_bench.png`，或者一张只有三行的表：

| 配置（口径 A：B200，2000 / 2000） | SQA | TextVQA |
|---|---|---|
| MAS（分模态） | 78.65 | 63.47 |
| 统一 scale + **同样校准、同样训练** | 78.70 | 64.39 |
| 差异（95% CI） | −0.05 [−1.35, +1.25]，p=0.97 | −0.92 [−2.41, +0.63]，p=0.25 |

页脚加一行小字（**PPL 不要放进这张表**，它是另一套口径）：
`PPL 上同样打平：16.19±0.34 vs 16.20±0.33，p=0.97（原实验机，ratio=0.75、匹配初始化统计）`

**口播**：

> 到这里我们想问的是：这三个点到底是哪儿来的。论文归因给「分模态」。
> 所以我们把变量控住：给统一平滑**同样的校准数据、同样的初始化统计、同样的训练轮数**。
> 结果是 78.70 对 78.65，差 0.05；TextVQA 上统一那边甚至高 0.9 点；都不显著。PPL 上 p=0.97。再加一组无标签的 KL 保真度，**三组独立证据一致**。
> 所以结论不是「论文错了」，是**归因错了**：增益来自「从闭式解变成可学习」这一步，而不是「分开学」这个结构。
> 这个坑我们自己先踩过——早先用不匹配的初始化统计，得到过「分模态显著更好，p=0.004」；换成匹配统计之后，差异从 −1.24 塌到 −0.01。

**任务**：全场第一个高点。技巧是**先暴露自己的错误**（p=0.004 → p=0.97），再给出结论——
这比直接说「论文归因错了」可信得多，也是评委最认的科研素养。

### P7 · 改进 F：GPTQ + clip（120s）★★ 全场最高点

**页面**：一页，分三层，从上到下：

1. 顶部一句话：`平滑只决定「量化什么」，没决定「怎么舍入」`
2. 中间：`RTN` →（误差反馈：把这一列的舍入残差补偿给还没量的列）→ `GPTQ`，配一张**误差扩散抖动**的示意（Floyd–Steinberg 的经典图或自己画的箭头图）
3. 底部：`+ clip（1 个元素亏，15 个元素赚）`，右侧贴结果条：`63.5 → 71.0，+7.5 [+5.8, +9.2]`

**口播（务必按这个顺序讲，这是全稿最重要的一段）**：

> 下游收益最大的改进是这个。
>
> 论文的平滑只回答了「**量化什么**」——它给权重挑了个更好的坐标系；但权重本身还是逐个四舍五入，也就是 RTN。而离群值被搬到权重上之后，恰恰是权重最难舍入的时候。
> 一个旁证：完全不平滑的 RTN 崩到 PPL 6103，可它的单层信噪比只比论文方法低 0.3 dB——**均值指标看不出这种崩坏，说明误差主体在权重。**
>
> 所以我们把 RTN 换成 **GPTQ**。它的类比很好记：就是图像里的**误差扩散抖动**。逐列量化，每一列舍入产生的残差，补偿给后面还没量的列；区别只在扩散核——图像里是固定的手工核，这里是从数据统计出来的**逆 Hessian**，也就是「哪些输入通道经常被一起激活」。**16 个码字一个都没变，变的只是每个权重最终落到哪个码字上。**
>
> 搬到多模态要重新想两件事：Hessian **在平滑空间**统计，那才是这份权重真正看到的输入；以及**按模态**取 token。
>
> 再加一个 **clip**。默认步长隐含「每行最大值必须无损」，代价是为一个值把其余格距撑粗了。所以让最大值轻微削顶，换大多数元素更细的格距。关键是互补性：**clip 单独配 RTN 不赚**，削顶纯亏；**必须配 GPTQ 才赚**，因为误差反馈会把削顶的损失甩给后面的列补偿。
>
> 结果：TextVQA **63.5 到 71.0，+7.5 点**，格式不变、推理零开销，与 FP16 的差距从 12.4 缩到 4.0。
> 最后一个多模态特有的前提，也是整条线的收口：**Hessian 也需要模态平衡的校准集**。原校准集上，同样的 GPTQ 让 **9 个 checkpoint 全部变差**。也就是说——**不先修校准集，更强的方法反而有害。**

**任务**：让全场听懂一个技术细节，并且记住「误差扩散抖动」这个类比。
**这一段是唯一允许超 10 秒的地方，因为它是拿分点；但绝不允许加第 4 个方法**（cd 不讲，留在问答里，见 §4.3 末段）。

**口播**：

> 剩下三条一句话带过。
> 论文另一个核心机制 CMC——低秩补偿——我们补了 4000 题下游：论文默认配置让 TextVQA 掉 6.9 点，**显著**；而**不加任何旁路、所有 token 只用文本尺度，反而和理想上界打平**。我们之前有一条「自适应秩省 7.8% 参数」的改进，因此**撤回**。

> 工程上修了 7 个 bug，按模态 gather 的单遍前向带来 3.8 倍和 9.2 倍加速，输出逐位一致。视频模态和 W4A6 的结果在报告里。

## 4. 三个难点的具体讲法（都是「一句话定性 + 不解释机制」）

### 4.1 什么是量化（20 秒，P2 开头）

> 「把 fp16 的权重和激活换成 4 bit，模型小四倍，代价是掉点。难点是激活里有离群通道。」

**只讲结论，不讲**：量化误差怎么算、per-token 和 per-channel 的区别、为什么选 4bit、有没有硬件支持。
如果评委追问，一句话：「权重按每个输出通道一个步长，激活按每个 token 一个步长，是这套方法的标准配置。」

### 4.2 MASQuant 与 SmoothQuant 的关系（15 秒，P2 中段）

你的理解是对的，而且这个理解**恰好是最好的讲法**：

> 「MASQuant 可以理解成 **SmoothQuant 的多模态版**：SmoothQuant 用一套缩放，MASQuant 给每个模态各一套，再把多出来的权重用低秩旁路省掉。」

**为什么这样讲最好**：听众里只要有人知道 SmoothQuant，这一句就把整个方法定位完了；不知道的人也能听懂「一套 vs 多套」这个差别。
**不要讲**：$\beta=0.5$ 的闭式解、为什么用 L1 loss、为什么 down_proj 不平滑。

### 4.3 GPTQ + clip（120 秒，P7）——按这个三层结构

这是全稿唯一需要「讲透机制」的地方。三层，缺一层效果就掉一半：

| 层 | 说什么 | 为什么必须有这一层 |
|---|---|---|
| ① 类比 | **误差扩散抖动**：逐列量化，每列舍入的残差补偿给后面还没量的列；扩散核从手工核换成从数据统计的逆 Hessian | 只要听众见过图像抖动，一句话就懂了 GPTQ 在干什么 |
| ② 多模态的改动 | Hessian **在平滑空间**统计、**按模态**取 token | 否则「GPTQ 是现成方法，你们创新在哪」这个质疑挡不住 |
| ③ clip 的互补性 | 削顶 = 1 个元素亏、15 个元素赚；**单独配 RTN 不赚，必须配 GPTQ 才赚**，因为误差反馈会把削顶的损失甩给后面的列 | 这是全稿最漂亮的一个「机制解释」，也是 clip 为什么算改进的唯一理由 |

**「GPTQ 不是已有方法吗」的标准答法**（也要背下来，场上一定被问）：

> 「GPTQ 是现成方法，我们没改它的内核。多模态下要回答三个问题：Hessian 在哪个空间统计、用哪些 token、校准集要满足什么条件。
> 第三个问题给出了一个反直觉的结论——在原校准集上，同样的 GPTQ 让 9 个 checkpoint 全部变差。
> 另外 clip 是我们自己的：它不是简单套现成方法，而是在 GPTQ 的误差反馈机制上才成立的互补技巧。」

**cd 要不要提**：讲了 10 秒的收益是「显得我们做了消融」，成本是「听众记得的东西变多、clip 的互补性被稀释」。
**建议不讲**。如果评委问「还能怎么改进」，答：

> 「我们试过坐标下降抛光，解完之后逐个元素重选码字。它在代理误差上确实更好——恢复率从 76% 到 87%——但端到端 PPL 没有一致收益，成本还乘五，所以默认不开。
> 从算法上看这个问题是离散二次规划、NP-hard，RTN 完全不协同，GPTQ 是贪心连 1-opt 都不满足，加上坐标下降到 1-opt，再上 2-opt 基本没收益——**求解器这一侧已经饱和了**。」

这段话放在问答里，效果比放在正文里好十倍：它证明你知道自己在哪一层最优里。

## 6. 两分钟问答：Top 10 + 一句话答案

> 原则：**先给一句话结论（加粗那句），对方追问再展开。**
> 每题控制在 25 秒内，2 分钟最多答 4~5 句。不会的直接说「没做」，再说「我们的判断是……」。

| # | 问题 | 一句话答案 |
|---|---|---|
| Q1 | **既然分模态没用，论文是不是错了？** | **不是动机错了，是归因错了**：视觉离群值污染其它模态这个现象我们复现了；但给统一平滑同样的校准和训练后，两者打平，论文的提升来自「从闭式解变成可学习」。 |
| Q2 | **不显著不等于没差异，样本够吗？** | **够，而且我们报的是 CI 不是 p**：SQA 上差异的 95% CI 是 [−1.35, +1.25]，能排除 1.3 个点以上的差异；PPL 上每侧 3~14 次重复。 |
| Q3 | **Eq.(17) 凭什么说写反了？** | **检验极端情况**：所有通道的模态范围比相等时，错位损失应为 0；按原式算不为 0，按论文自己的推导（Eq.20）重推，分子分母要互换。 |
| Q4 | **GPTQ 不是已有方法吗？创新在哪？** | 见 §4.3 末段。**三个设计问题 + 一个反直觉结论（原校准上 9/9 更差）+ clip 是必须配 GPTQ 才成立的互补技巧。** |
| Q5 | **为什么只用 3B？** | **官方示例脚本默认就是 3B**。3B 单卡一轮 5~7 分钟，我们才能做 130 多次独立训练来支撑重复和显著性检验；7B 会降到十几次，做不了检验。代价是外推受限，写在局限里。 |
| Q6 | **为什么只有两个 benchmark？** | **评测链路限制**：MMMU 需要外部 judge，OCRBench 的聚合指标在现有调用路径下拿不到。**我们选择的是「两个但全量 + 配对检验」，而不是「多但只跑 10%」**。 |
| Q7 | **求解器还能再挤吗？** | **基本不能**。见 §4.3 末段的 cd 回答：1-opt 已是很强的吸引子，2-opt 无额外收益，是离散二次规划在求解器这一侧饱和。 |
| Q8 | **NVFP4 下为什么 GPTQ 没用？** | **16 元素块缩放已经把权重误差吸收掉了**，RTN 本身就接近 FP16。所以我们的 GPTQ 是针对 INT 的 per-channel 粗粒度格点的。 |
| Q9 | **你们的方法能推广到别的模型吗？** | **没验证**。音频模态的校准配比问题应该更突出，我们的结论应该更成立，但没有实验支持——这是接下来第一件事。 |
| Q10 | **结论大部分是负面的，价值在哪？** | **把「有效在哪里」说清楚了**：收益来自校准配比和权重求解器，不是「分模态 + 补偿」这套结构；并且给出一个更简单、更好的部署方案。对后来做 MLLM 量化的人，「先检查校准集」是可直接用的结论。 |

### 6.1 两人怎么分问答

- **A 主答**：Q1、Q2、Q3、Q5、Q6（论文与方法、实验设置）
- **B 主答**：Q4、Q7、Q8、Q9（求解器、格式、拓展）
