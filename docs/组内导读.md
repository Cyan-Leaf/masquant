## 0. 三十秒版本

**论文**提出：多模态大模型做量化时，不同模态的激活量级差 10–100 倍，一套平滑因子只能迁就"最强势"的模态（通常是视觉），
导致文本/音频被压坏。它给出两招：**MAS**（每个模态一套可学习的平滑因子）和 **CMC**（只存一份量化权重，其它模态用低秩矩阵补偿）。

**我们**在 Qwen2.5-VL-3B 上复现了 W4A8 全流程，然后做了五件事：
1. 复现验证：MAS 显著优于 SmoothQuant ✅（与论文方向一致）
2. 指出并实测了一个论文没讨论的问题：**校准集里文本 token 只占 8.1%**，据此提出"混合校准"，PPL 18.46→16.2、方差降到 1/4，
   并做了**跨领域（C4）验证**证明不是作弊 ✅
3. 但严格控变量后，**"分模态"这个设计本身没有带来增益**（PPL p=0.97、两个全量 benchmark、KL 保真度三组证据一致）—— 这是我们的核心发现
4. 拓展：**NVFP4 W4A4**（下游几乎无损，比 INT W4A8 高 10 个点）、**视频模态**（论文没做）
5. 补做论文最关键的 **CMC** 的下游评测，发现**论文默认配置在我们训练出的模型上显著有害**（TextVQA −6.9），并诊断出原因

**一句话**：论文的动机成立，但"分模态"和"低秩补偿"这两个具体设计在我们的设置下都不带来增益；
真正有效的是**校准数据的模态平衡**，而最简单的部署（一份权重、零旁路）反而最好。

**2026-11-23 晚新增（创新性的主打）**：第 6 件事 —— **平滑之后把 RTN 换成多模态感知的 GPTQ**（`docs/改进F_平滑后GPTQ.md`）。
MAS 只回答"量化什么"，权重仍逐元素四舍五入；我们在平滑空间里按模态统计 Hessian 做 GPTQ，再按 Hessian 误差逐行裁剪步长。
TextVQA 63.5 → 71.0 ~ 73.5（FP16 75.9），C4 PPL 每个 checkpoint −2.1；且**只有在混合校准下才有效**（原校准上 9/9 变差），
正好把"校准集模态平衡"从"让 MAS 训练更稳"升级成"让更强的求解器能用"。答辩时建议把它放在第 5 页，和混合校准连起来讲：
"发现校准失衡 → 修校准 → 修校准之后才能用更强的权重求解器 → 下游 +7.5 点"。

可能被问：
- *GPTQ 不是已有方法吗，创新在哪？* —— 多模态下怎么用才是问题：Hessian 在哪个空间统计（平滑后）、用哪些 token（本模态）、
  校准集要什么条件（模态平衡，否则过拟合模板文本，9/9 变差），以及 clip 与 GPTQ 的互补（INT per-channel 下 clip 单独也有效）。
- *为什么 NVFP4 下没用？* —— 16 元素块缩放已经把权重误差吸收掉了，RTN 本身就接近 FP16。
- *那还需要 MAS 吗？* —— 好的求解器下，不平滑/闭式解/统一/分模态两两大多不显著；W4A8 主瓶颈在权重。

## 1. 论文在解决什么问题（必要背景）

### 1.1 PTQ 与平滑

训练后量化（PTQ）的难点是**激活里的离群通道**：某一维的激活值比其它维大几百倍，per-token 量化的步长被它决定，
其它维全被压成 0。SmoothQuant 的做法是做一个等价变换

$$Y = (XS^{-1})(SW),\qquad S=\mathrm{diag}(s),\ s_i=\frac{\max_t|x_{t,i}|^\beta}{\max_j|w_{j,i}|^{1-\beta}}$$

把激活的离群值"搬"到权重上。这是恒等变换，数学上无损，但量化后就不同了：好的 $s$ 能让激活和权重都落在合适的动态范围里。

### 1.2 多模态为什么会出问题（论文的动机，也是我们认可的部分）

MLLM 里视觉 token 的激活量级比文本大 1–2 个数量级。一套统一的 $s$ 只能迁就其中一方：

- $s$ 跟着视觉走 → 文本被一个"为视觉量身定做"的尺度除，信号被过度压缩；
- $s$ 跟着文本走 → 视觉的离群值把量化步长撑爆。

论文把这个叫 **Smoothing Misalignment（平滑错位）**，并用 Theorem 1 量化了损失：
令 $\alpha_i = R_i^{\text{强}}/R_i^{\text{弱}}$ 为两个模态在第 $i$ 个通道上的范围比，

$$\Delta = 10\log_{10}\Big[\frac{(\min_i\alpha_i)^2}{d}\sum_{i=1}^{d}\frac{1}{\alpha_i^2}\Big]\le 0$$

当且仅当所有 $\alpha_i$ 相等时为 0。**注意：论文 Eq.(17) 把分子分母写反了**（按原式，$\alpha$ 全相等时算出来不是 0）。
这是我们精读时发现的问题，答辩可以点出来，是"读懂了"的证据。

### 1.3 论文的两招

**(a) MAS（Modality-Aware Smoothing）**：每个模态一套 $s_m$，用该模态自己的激活统计做闭式解初始化
（$\beta=0.5$，但 max 只在该模态的 token 上取），然后逐层训练，目标是最小化重建误差

$$\min_{\{S_m\}}\sum_m \lambda_m\,\big\|Q(X^mS_m^{-1})\cdot Q(S_mW) - X^mW\big\|_1$$

用 L1 而不是 MSE，理由是"对离群值不敏感"。

**(b) CMC（Cross-Modal Compensation）**：分模态平滑的代价是每个模态需要一份量化权重 $Q(S_mW)$，显存 ×3，量化的意义就没了。
CMC 只存文本的 $Q(S_tW)$，其它模态额外加一条低秩旁路补偿差异：

$$Y = Q(X_mS_m^{-1})\cdot Q(S_tW) + X_mS_m^{-1}L_1^mL_2^m$$

**Theorem 2** 说：先对输入做白化（$T$ 由视觉激活协方差特征分解得到），再对 $T\Delta W$ 做截断 SVD，
就是输出误差意义下的最优低秩近似。因为 decode 阶段只有文本 token，这条旁路只在 prefill 触发，论文声称额外开销约 2% FLOPs。

### 1.4 论文声称的结论

- Qwen2.5-VL W4A8：MASQuant 平均 64.7 分，SmoothQuant 57.4，RTN 5.1（崩）；
- Qwen2.5-Omni 上把 SmoothQuant 崩到 77.4 的语音识别 WER 救回 3.6；
- 消融（Table 3）：**"可学习优化会放大分模态相对统一平滑的优势"** —— 这一条我们没能复现，见 §3.2。

## 3. 我们得到了什么（结论台账）

**这是最重要的一张表。每条都标了状态，撤回的也留着并写明原因——这本身就是工作质量的一部分。**

### 3.1 ✅ 复现成功（硬结论）

W4A8，Qwen2.5-VL-3B，配对 bootstrap：

| 配置 | ScienceQA (2017) | TextVQA (2000) | wikitext2 PPL |
|---|---|---|---|
| FP16 | **80.61** | **75.78** | 11.11 |
| SmoothQuant | 75.51 | 62.58 | 22.63 |
| MAS（论文配置，原校准） | — | — | 18.46 ± 1.43 |
| **MAS + 混合校准（我们的改进）** | **79.38** | **65.98** | **16.35 ± 0.54** |
| 统一 scale + 同校准同训练（对照） | 78.98 | 65.45 | 17.20 ± 0.82 |
| MAS + LWC | 75.81 | 58.09 | 15.45 |

- MAS − SmoothQuant = **+3.17 [+1.54, +4.81]** / **+3.41 [+1.74, +5.10]** → 显著；
- MAS − FP16 = **−1.93 [−3.32, −0.55]** / **−9.79 [−11.42, −8.18]** → **W4A8 没有追平 FP16**（早期 1000 题时我们误以为追平了）；
- 论文 Table 5 报 epoch=2 时 PPL 18.6，我们 18.46 —— **均值几乎一致**。

### 3.2 ❌ 核心发现：分模态本身没有增益（我们最重要的结论）

给"统一 scale"**同样的校准数据和同样的训练**之后，两者完全打平：

| 对比 | ScienceQA | TextVQA | PPL |
|---|---|---|---|
| MAS − 统一 scale（ratio=0.75，匹配统计） | −0.15（不显著） | +1.02（不显著） | 16.19 vs 16.20，**p=0.97** |

加 KL 保真度（无标签评测）共**三组独立证据**。结论：论文的提升来自"从闭式解变成可学习"这一步，
而不是"分模态"这个结构。论文 Table 3 的"优化会放大分模态优势"在本设置下未复现。

> 这条是汇报的主线。它不是"论文错了"，而是"论文归因错了"——动机对，设计的必要性没有证据。

### 3.3 ✅ 最有价值的改进：校准集的模态平衡

统计发现原校准集 128 个样本的 token 构成是**图像 43658 / 文本 3873，文本只占 8.1%**，且文本基本是重复的对话模板。
MAS 要给文本单独学一个尺度，等于几乎无监督。

| 纯文本样本占比 | 0（原） | 0.375 | **0.5（默认，推荐）** | 0.75 | 0.875 |
|---|---|---|---|---|---|
| MAS PPL | 18.46 ± 1.43 | 16.74 ± 0.52 | **16.35 ± 0.54（6 次）** | 16.19 ± 0.34 | 16.29 ± 0.45 |

曲线在 0.375~0.875 是**宽平台**，不必精调。

**关键验证（最该讲的一步）**：wikitext 既是补充的校准文本又是 PPL 测试集，有"同域作弊"的嫌疑。
换到 **C4** 重测（B200 上更大样本复核）：原校准 **20.40 ± 0.46（9 次）** vs 混合校准 **18.88 ± 0.50（14 次）**，
**p=0.0001**，收益保留约 80%。**所以这是真实改进。**
下游不受影响（0.5/0.75/0.875 两两不显著），方差还降到约 1/4。

### 3.4 ✅ 拓展：NVFP4 W4A4（比原计划强得多的结果）

论文只做 INT。我们实现 NVFP4（E2M1 + FP8 块缩放，每 16 个元素一个块 scale）：

| 配置 | 位宽 | wikitext2 PPL | ScienceQA | TextVQA |
|---|---|---|---|---|
| FP16 | 16/16 | 11.11 | 80.80 | 75.85 |
| INT4A4 RTN | 4/4 | **96377（崩）** | — | — |
| **NVFP4 + MAS 闭式解** | **4/4** | **11.75** | **80.45**（与 FP16 无显著差异） | **73.64**（仅差 2.2） |
| MAS（INT） | 4/8 | 16.35 | 78.65 | 63.47 |

**同为 4-bit 权重，FP4（激活也 4-bit）在 TextVQA 上比 INT（激活 8-bit）高 10 个百分点。**
这说明多模态量化的瓶颈不只是"位宽"，而是**格式能否适应视觉 token 的离群分布**。

注意一个反直觉的点：**NVFP4 下训练反而略差**（12.14 ± 0.03 vs 闭式解 11.75），
我们用"缩放尺度重测 PPL"的实验否证了最初的解释，原因尚未查清。**实用建议：FP4 下直接用闭式解。**

### 3.5 ✅ 拓展：W4A6 的下游（PPL 看不出的崩坏）

| W4A6 | PPL | ScienceQA | TextVQA |
|---|---|---|---|
| SmoothQuant | 26.72 | 71.60 | 53.32 |
| MAS + 混合校准 | 24.48 | **75.85** | 53.12 |

**激活从 8bit 降到 6bit，PPL 只从 16.3 涨到 24.5，但 TextVQA 从 63.5 崩到 53.1。**
这是"PPL 不能代表 MLLM 量化质量"的又一个例子。

### 3.6 ❌ 补做 CMC 下游：论文默认配置显著有害（重要的负面结果）

论文最核心的机制之一是 CMC。我们此前只有 n=500 的评测（无显著差异），这次补到全量：

| 部署方式 | 额外参数 | ScienceQA | TextVQA |
|---|---|---|---|
| **只用文本尺度、不补偿** | 0 | **79.55** | **63.35** |
| 视觉单独一份权重（CMC 想逼近的上限） | 多一份权重 | 78.65 | 63.47 |
| CMC rank 0.05（**论文默认**） | ~1 GB | 78.45 | 56.48（**−6.86，显著**） |
| CMC rank 0.2 | ~4 GB | 79.30 | 62.24 |
| CMC + 自适应秩（我们原来的"改进"） | ~0.96 GB | 75.40 | 51.04（**−12.30，显著**） |

- 同一配置独立跑两次，逐题结果**逐字节相同**，不是噪声；
- **"不补偿"与理想上限打平**：混合校准之后，文本尺度对视觉 token 已经够用；
- **我们原来的"自适应 rank 省 7.8% 参数、PPL 不变"这条改进撤回**——PPL 是纯文本测的，根本不经过视觉旁路。

**机制（`tools/cmc_probe.py`，逐模块 SQNR）**：CMC 的**平均** SQNR 反而最高（18.05 dB，甚至高于上限 17.17 dB，
因为低秩项顺带补了权重量化误差），但 72 个模块里 **23 个被补偿坏**，例如 `layers.3.k_proj` 从 12.1 dB 掉到 3.5 dB。
**平均值掩盖了少数模块的崩坏** —— 和我们踩过的 RTN 坑是同一个教训。

### 3.7 ⚠️ 工程：7 个实现 bug + 一个会骗人的指标

| bug | 影响 |
|---|---|
| `snr_probe.py` 构造了权重量化器却从未调用 | 只量化激活，量出来的不是 W4A8 误差（旧结论"视频掉 7 dB"作废） |
| `snr_probe.py` uniform 模式读错 key，静默回退成 text 尺度 | "统一 scale" 一列算错 |
| `fidelity_eval.py` 先拷尺度后加载 | 等价于裸 RTN，KL 虚高 3.6 倍 |
| `reuse_scale` 漏拷 `video_smooth_scale` | k/v/gate 视频尺度一直是全 1 |
| LWC 参数没进优化器 + dtype 崩溃 | `--lwc` 实际不可用 |
| 纯文本样本复用上个样本已 backward 的 `vision_diff` | "backward twice" |
| `modeling_qwen2_5_vl.py` 只传 `(None, image_mask, text_mask)` | 视频 token 被当成文本，视频模态完全失效 |

**加速**：按模态 gather 的单遍前向 + 量化权重缓存，单层 prefill **3.84×**、decode **9.24×**，输出逐位一致。
（原实现对每个模态各跑一遍完整 GEMM 再按 mask 相加，实际部署是 3–4× 计算量，论文没讨论。）

### 3.8 ✅ 复现性诊断（换机器后能否复现）

第一轮在 4×B200 上复跑得到 15.7/17.7/22.9/35.5，看起来"复现不出来"。排查结论：

- **不是 GPU 型号问题**：同一张卡、同一种子，连续两次就不同（19.19 / 17.57）；
- 噪声来自训练时 attention 反向的**非确定性原子累加**：`MAS_DETERMINISTIC=1` 下两次 PPL 逐位相同；
- **冻结 checkpoint 后评测完全可复现**（三张卡上同一个数），所以报告里所有 benchmark 数字都能逐题复算；
- 跨硬件的系统偏移来自 `act_scales`（"取最大值"的统计对前向微小差异极敏感，同数据重算只有 255/1008 个张量逐位相同）；
- 那个 35.5 是一次**训练早期发散**（第 1 层 loss 一开始就 1.9 倍），18 次里 1 次；
- **主结论在 B200 上全部复现**：MAS−SQ 显著、MAS−统一打平、混合校准 C4 p=0.0001、W4A8 未追平 FP16。

#### A. 论文理解类

| # | 可能的问题 | 回答 |
|---|---|---|
| A1 | 用一句话说 MASQuant 解决什么问题？ | **一套平滑因子在多模态模型上只能迁就激活最大的模态（通常是视觉），弱模态被压坏；MASQuant 给每个模态各学一套，再用低秩补偿避免存多份权重。** |
| A2 | SmoothQuant 本来就是恒等变换，为什么还会掉点？ | **恒等是在浮点下；量化后不同 $s$ 决定了激活和权重各自落在什么动态范围，误差不同。**$s$ 选错，某个模态的量化步长就被离群值撑大。 |
| A3 | 为什么不直接给每个模态存一份量化权重？ | **显存 ×模态数，4-bit 的压缩意义就没了**。CMC 就是为了避免这一点：只存一份 $Q(S_tW)$，其它模态用低秩旁路补。 |
| A4 | 为什么 CMC 选文本当基准模态？ | **decode 阶段生成的全是文本 token**，以文本为基准，低秩旁路只在 prefill 触发，decode 零额外开销。 |
| A5 | Theorem 2 的核心是什么？ | **把"加权的低秩逼近"变成"标准低秩逼近"**：先用激活协方差白化，$\|X(\Delta W-L)\|_F=\|T\Delta W-TL\|_F$，于是截断 SVD 就是最优解（Eckart–Young）。 |
| A6 | 你们说 Eq.(17) 写反了，怎么确定的？ | **检验极端情况：所有通道的模态范围比 $\alpha_i$ 都相等时，错位损失应为 0**，按原式算出来不为 0；按论文自己的推导过程（Eq.20）重推，分子分母应该互换。 |
| A7 | 论文的 loss 为什么用 L1？ | 论文的理由是**对离群值不敏感**。我们没有做 L1 vs L2 的消融，沿用了论文设置。 |
| A8 | 论文说 $\lambda_v=1.0$，你们用的是多少？ | **代码默认实际是 0.5**（没传 `--grad_info_path` 时），和论文描述不一致。我们实测 1.0 更差：20.73 ± 2.46 vs 18.46 ± 1.43。 |

#### C. 核心结论：分模态 vs 统一

| # | 可能的问题 | 回答 |
|---|---|---|
| C1 | 你们说"分模态没用"，是不是论文错了？ | **不是论文的动机错了，是归因不对。** 视觉离群值污染其它模态这个现象成立；但给"统一平滑"同样的训练和校准后，它和分模态打平。论文的提升主要来自"从闭式解变成可学习"。 |
| C2 | "打平"的证据是什么？ | **三组独立证据**：PPL 16.19 vs 16.20（p=0.97）；两个全量 benchmark 配对差异 −0.15 / +1.02，CI 都跨零；KL 保真度 1.53 vs 1.55。换到 B200 再测一遍也打平。 |
| C3 | 不显著不等于没差异，你们样本够吗？ | **对，所以我们报的是 CI 而不是只说不显著**：SQA 上差异的 95% CI 是 [−1.64, +1.34]，即能排除 1.6 个点以上的差异；PPL 用了 3–14 次重复。 |
| C4 | 论文 Table 3 显示分模态+优化比统一+优化好很多，为什么你们没复现？ | **我们的判断是对照组不公平**：如果统一 scale 的校准数据或初始化统计不同，就会产生假差异。我们自己就踩过——用不匹配的初始化统计时得到"分模态显著更好（p=0.004）"，换成匹配统计后差异从 −1.24 塌缩到 −0.01。论文没报告这些细节，我们无法确认。 |
| C5 | 单层 SQNR 上分模态是不是好一点？ | **是，约 1 dB**（text +0.97 / image +1.12 / video +0.26 dB，288 个配对，CI 不含 0），方向与论文一致。但这 1 dB 经过 36 层后在端到端被吸收了。 |
| C6 | 分模态在"必须读图"的题上会不会更好？ | **也没有**：必须读图组上 MAS − 统一 = +0.92，CI 跨零。排除了"分模态的好处被文字题稀释"这种解释。 |
| C7 | 原校准下统一 scale 的 PPL（15.02）比 MAS（18.46）还好，那论文方法岂不是更差？ | **只看 PPL 是这样，但 PPL 只测文本**。原校准下 MAS 的文本尺度几乎没有监督，所以文本 PPL 吃亏；统一 scale 用全部 token 拟合，不受影响。我们没有在原校准下给统一 scale 跑全量下游，所以不下"论文更差"的结论；控制校准后两者在 PPL 和下游上都打平。 |

#### D. 改进：混合校准

| # | 可能的问题 | 回答 |
|---|---|---|
| D1 | 为什么想到改校准集？ | **因为 MAS 的方差异常大**（同配置 17.0~19.9），追原因时统计了 token 构成：**文本只占 8.1%**（43658 图像 vs 3873 文本），而且文本大多是重复的对话模板——文本那套尺度几乎没有监督。 |
| D2 | 混合校准是不是"在 wikitext 上训练、在 wikitext 上测"，作弊？ | **这正是我们专门排除的**：换到 C4（不同领域）重测，收益保留约 80%，p=0.0001（B200 上 14 vs 9 次）。 |
| D3 | 比例怎么选？ | **文本样本占比 ≥40% 后进入平台**（0.375~0.875 之间 16.2~16.7），不用精调。我们推荐 0.5：是默认值，0.5 和 0.75 在两个测试集上都不显著且方向相反。 |
| D4 | 混合校准会不会伤视觉能力？ | **下游不掉**：0.5 / 0.75 / 0.875 在两个 benchmark 上两两差异都不显著。 |
| D5 | 这个改进对统一 scale 也有效吗？ | **主要是救 MAS 的**：统一 scale 用全部 token 拟合一套尺度，本来就不缺文本监督（原校准下 wikitext PPL 15.02 ± 0.15，反而比 MAS 的 18.46 好）。混合校准把 MAS 的文本尺度补上监督后，两者在 16.2 附近打平。所以论文"分模态更好"的结论还依赖于一个没被讨论的条件：校准集里文本够不够。 |
| D6 | 这算创新吗？只是换了数据。 | **创新点在于发现问题和证明它是真问题**：论文和官方代码都没讨论校准集的模态配比；我们定位到它是方差的主因，给出比例曲线，并做了跨领域验证。成本为零，收益大于方法层面的任何改动。 |

#### E. 拓展：NVFP4、视频、W4A6

| # | 可能的问题 | 回答 |
|---|---|---|
| E1 | NVFP4 是什么？ | **NVIDIA Blackwell 原生支持的 4-bit 浮点格式**：元素 E2M1（可表示 ±0.5~±6），每 16 个元素共享一个 FP8(E4M3) 缩放，再加一个张量级 FP32 缩放。 |
| E2 | 为什么 NVFP4 比 INT4 好这么多？ | **块级缩放把离群通道隔离在自己的 16 元素块里**，不会拖累整行。单层合成数据上 NVFP4 的 SQNR（22.4 dB）与 INT8 相当，INT4 只有 5.5 dB。 |
| E3 | 你们是真实 FP4 kernel 吗？有测速吗？ | **没有，是伪量化**（量化-反量化后用高精度算），只验证精度，没测速。这是局限。 |
| E4 | NVFP4 下 MAS 还有用吗？ | **闭式解初始化有用**（11.75 vs SmoothQuant 12.06），**训练反而略差**（12.14 ± 0.03）。我们否证了"训练把尺度推大"的假设，真实原因没查清。下游上 MAS 闭式解和 NVFP4 RTN 只差 0.1–0.2 点。 |
| E5 | W4A4 怎么能比 W4A8 好？ | **格式不同**：比的是 FP4 激活 vs INT8 激活。INT 的 per-token 量化一行只有一个步长，被视觉离群值撑大；FP4 的块级缩放没有这个问题。TextVQA 73.64 vs 63.47。 |
| E6 | 视频你们做了什么？ | **把 MAS 扩展到视频 token**（Qwen2.5-VL 有独立的 video token），修了原代码丢弃 `video_mask` 的问题。结论是独立视频尺度相比复用图像尺度**不显著**（各 3 次），默认复用。数据是 COCO 拼的合成视频，置信度最低。 |
| E7 | W4A6 的结果说明什么？ | **激活降到 6 bit 时 TextVQA 崩到 53，而 PPL 只从 16.3 涨到 24.5**——PPL 完全看不出这个崩溃。ScienceQA 上 MAS 仍显著优于 SQ（+4.25）。 |

#### F. CMC（低秩补偿）

| # | 可能的问题 | 回答 |
|---|---|---|
| F1 | 你们说 CMC 有害，是不是实现错了？ | **我们用的是官方实现**，并做了三个检查：① 旧 checkpoint 上 CMC 只是小幅有害且两台机器一致，说明流程本身没坏；② 同一配置独立评测两次逐字节相同；③ 逐模块诊断能定位到具体被补坏的层。 |
| F2 | 为什么平均 SQNR 最高，下游反而最差？ | **平均值被多数正常模块拉高，掩盖了少数崩坏的模块**：72 个模块里 23 个变差，`layers.3.k_proj` 从 12.1 dB 掉到 3.5 dB。K 投影出错会直接破坏注意力分布。 |
| F3 | 为什么在你们的 checkpoint 上有害，在旧的上不明显？ | **混合校准后文本尺度对视觉 token 已经接近最优**（不补偿 16.82 dB vs 理想 17.17 dB），能补的空间很小，而 5% 秩截断后的残差反而更大；旧 checkpoint 上差距是 2.1 dB，有东西可补。 |
| F4 | 加大秩不就好了？ | **rank 0.2（4 倍参数）才回到"不补偿"的水平，但不超过它**。既然不补偿就一样好，加低秩旁路没有意义。 |
| F5 | 你们的自适应秩为什么撤回？ | **它只在 PPL 上验证过，而纯文本 PPL 根本不经过视觉旁路**——我们自己当时也写了这一点却仍下了结论。补做下游后它显著更差（TextVQA −12.3），所以撤回。 |
| F6 | 那你们的部署建议是什么？ | **混合校准训练 MAS，部署时所有 token 只用文本尺度，一份 4-bit 权重，不加旁路**。与理想上界打平，显著优于论文默认 CMC，零额外参数。 |

#### G. 统计与可复现性

| # | 可能的问题 | 回答 |
|---|---|---|
| G1 | 什么是配对 bootstrap？为什么用它？ | **在同一批题目上，对"两个配置的逐题对错差"做有放回重采样（10000 次），得到差异的 95% CI**。同题配对消掉了题目难度的方差，比各自算 CI 再比较灵敏得多。 |
| G2 | 为什么同一配置要跑那么多次？ | **训练是非确定性的**：同一张卡、同一种子，连跑两次 PPL 可差 1.6，四次跨度 3.8。报单次没有意义。 |
| G3 | 非确定性从哪来？ | **attention 反向的原子累加，归约顺序不固定**。开 `MAS_DETERMINISTIC=1`（禁 flash/mem-efficient SDPA、固定 cuBLAS workspace）后两次逐位相同。但这个模式精度偏低，只用于排查。 |
| G4 | 换一台机器能复现吗？ | **结论能，数字不能逐位复现**。我们在 4×B200 上整套复跑：MAS 显著优于 SQ、分模态与统一打平、混合校准 C4 上 p=0.0001、W4A8 未追平 FP16——全部复现。绝对 PPL 差约 1 个点，在训练噪声范围内。 |
| G5 | 你们的数字别人能核对吗？ | **能**。冻结 checkpoint 后评测逐位可复现（三张卡同一个数）；仓库 `results/` 存了所有逐题预测和 bootstrap 结果，`RESULTS_MAP.md` 把报告里每个数字对应到脚本和原始文件。 |
| G6 | 有没有某次结果特别离谱？ | **有，一次 35.5**。逐层看 loss，第 1 层从第一个 epoch 起就是正常值的 1.9 倍，是一次训练早期发散，18 次里出现 1 次。这也是我们报中位数和更稳的 C4 的原因。 |
| G7 | 降低学习率能不能让结果更稳？ | **方差确实变小，但均值稳定地更差**（C4 20.43 ± 0.12 vs 18.88 ± 0.50），2 epoch 内收敛不够。不是解决办法。 |

#### H. 工程与 bug

| # | 可能的问题 | 回答 |
|---|---|---|
| H1 | 你们修了哪些 bug？最严重的是哪个？ | **7 个**。原仓库：LWC 参数从没进优化器且一开就崩、纯文本样本会触发 backward twice、视频 mask 被丢弃、`reuse_scale` 漏拷视频尺度。我们自己的工具：SQNR 探针**构造了权重量化器却忘了调用**（最严重，曾让我们得出"视频掉 7 dB"的错误结论）、uniform 模式读错 key、保真度评测加载顺序错误。 |
| H2 | 你们怎么发现自己工具的 bug 的？ | **代理指标和端到端结论矛盾时回头查**：探针说统一平滑让视频掉 7 dB，但下游和 KL 都打平，于是逐行查探针，发现只量化了激活。 |
| H3 | 加速是怎么做的？ | **原实现对每个模态各跑一遍完整 GEMM 再按 mask 相加**（3–4 倍计算）。我们按模态 gather 只算本模态的行，并缓存量化后的权重：单层 prefill 3.84×、decode 9.24×，输出逐位一致。 |
| H4 | LWC 修好之后效果如何？ | **PPL 最低（15.45），但两个下游都显著变差**（SQA −2.88、TVQA −7.91）。这是"PPL 不能代表 MLLM 量化质量"最强的反例。 |
| H5 | 平滑因子出现负值是什么问题？ | 训练出的尺度有 0.2~0.4% 的通道为负，因为既没有符号约束也没有投影。**实测影响可忽略**（全部翻正后 PPL 差 0.06），加约束也没有收益。论文没讨论。 |

## 8. 术语最小集

| 术语 | 一句话 |
|---|---|
| PTQ | 训练后量化，不改训练流程，只用少量校准数据定量化参数 |
| W4A8 / W4A4 | 权重 4bit、激活 8bit / 4bit |
| per-token / per-channel | 激活按每个 token 一个量化步长；权重按每个输出通道一个 |
| 平滑因子 $s$ | SmoothQuant 的逐通道缩放，把激活的离群值搬到权重上 |
| 平滑错位 | 一套 $s$ 无法同时适配量级差 10–100× 的不同模态 |
| MAS | 每个模态一套可学习 $s_m$ |
| CMC | 只存一份量化权重 + 低秩旁路补偿其它模态 |
| 白化 | 用激活协方差把输入变成各向同性，使"模态间权重差"呈现低秩 |
| 闭式解初始化 | 不训练，直接用 $\sqrt{\max|x|/\max|w|}$ 这类解析公式定 $s$ |
| 配对 bootstrap | 同一批题目上逐题比较两个配置，用重采样给差异的 95% CI |
| SQNR | 输出信噪比（dB），单层量化误差的代理指标 |
| KL 保真度 | 量化模型与 FP16 模型下一个 token 分布的 KL 散度，无需标签 |
